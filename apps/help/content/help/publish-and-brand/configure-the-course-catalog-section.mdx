---
title: Configure the course catalog section
description: Choose which published courses appear first on the public course list.
last_reviewed: '2026-11-13'
---

The **Courses** section in **Distribute → Landing Page → Customize** chooses up to four published courses and their order for the public list at `/courses`. The academy homepage does not list courses. The editor preview still shows the section so you can review layout.

1. Open **Distribute → Landing Page → Customize** and select **Courses**.
2. Choose **Add courses**, search for the courses you want, and select them.
3. Reorder the selected courses by dragging them into the display order you prefer.
4. Save, then open `/courses` on your live academy. The editor preview shows the section for layout only.

Only published courses can work as public destinations. If a course does not appear as expected, check its [publish and self-enrollment settings](/build-courses/publish-a-course-and-allow-self-enrollment).
