---
title: Integrations
description: Optional integrations for self-hosted ClassroomIO — Google OAuth, Unsplash, OpenAI, and branding.
---

These integrations are all **optional**: ClassroomIO runs without any of them. Add a variable only if
you use that feature; leaving it blank never causes a build or boot error.

## Google OAuth

Let users sign in with Google.

| Variable | Description |
|----------|-------------|
| `GOOGLE_CLIENT_ID` | Google OAuth client ID |
| `GOOGLE_CLIENT_SECRET` | Google OAuth client secret |

## OpenAI (transcription & AI course generation)

Powers uploaded-video transcription and AI course generation. Set the key on both the **API** and **jobs**
services; the API queues transcription and the jobs worker runs it. Redeploy both services after
setting the key.

| Variable | Description |
|----------|-------------|
| `OPENAI_API_KEY` | OpenAI API key — uploaded-video transcription + AI course generation |

:::tip[Disable AI features]
To hide all AI-related UI across the dashboard, see [AI features](/self-hosted/configuration/ai).
:::

## Unsplash

Enables the in-app Unsplash image search.

| Variable | Description |
|----------|-------------|
| `UNSPLASH_API_KEY` | Unsplash API access key |

## Branding & routing

| Variable | Description |
|----------|-------------|
| `PUBLIC_APP_NAME` | Name for logos, sign-in labels, the web app manifest, and browser-tab suffixes (`{page} - {name}`). When `PUBLIC_APP_TITLE` is unset, the default document title is `{name} \| Learning platform` |
| `PUBLIC_APP_TITLE` | Default document title and Open Graph site name when set. Takes precedence over `PUBLIC_APP_NAME` for that title |
| `PUBLIC_APP_DESCRIPTION` | Custom app description / meta tag |
| `PUBLIC_OG_IMAGE_URL` | Custom Open Graph image URL |
| `PUBLIC_SUPPORT_EMAIL` | Support address shown in the dashboard |
| `PUBLIC_TWITTER_HANDLE` | Twitter/X site handle for meta tags. Leave empty to omit it |
| `PUBLIC_SOURCE_URL` | HTTPS URL for the in-app source-code link. Defaults to this repository |
| `SUPPORT_EMAIL` | API and jobs. Password-reset help text and the default reply-to |
| `EMAIL_VIA_SUFFIX` | API and jobs. When set, org mail is from `Org Name (via suffix)` |
| `PRIVATE_APP_HOST` | Dashboard host for multi-subdomain routing |
| `PRIVATE_APP_SUBDOMAINS` | Subdomains served by the dashboard |

:::note[Enterprise features]
`LICENSE_KEY` unlocks Enterprise-only integrations such as SSO. See
[Enterprise & licensing](/self-hosted/enterprise).
:::
